# Observed and implemented behavior
The supplied prototype is a fixed 1920px design; at a narrow browser viewport it clips rather than providing a mobile layout. The editable design is the authority for colors, typography and sizing.

Observed in prototype: autoplay cloud video, a separate tower foreground, fixed navigation while scrolling, click-open solutions dropdown. Not every prototype navigation label has a destination wired.

Extracted Figma variants: solution cards reveal descriptive white translucent panels; About Vision/Mission replace icon with explanatory text over dark blur. These exact variants are implemented on hover/focus, with touch toggles for the purpose cards.

Implemented application behavior: supplied design pages navigate locally. Menu supports click, outside click and Escape; mobile menu is a stacked panel. FAQ is a native-button accordion with first answer open. Milestone arrows scroll the source cards within their viewport and disable at limits. Mail links launch the user's mail application; no mail is sent automatically.

The design contains no full mobile page frames. Under 768px, layout is an adaptation: readable typography, stacked sections, retained real images, menu toggle, and footer last. It is not claimed as an extracted mobile composition.

Source pages not supplied: dedicated Rapid Deployment, Smart Pole, Portfolio index, News/Events, CSR and legal pages. Their labels are retained; no invented page designs or copy are added. Portfolio navigation targets the supplied featured projects section.
